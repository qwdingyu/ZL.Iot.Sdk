# ZL.DB.Core 命名与 SqlSugarCore 的对应关系（改名决策记录）

日期：2026-10-07
范围：`src/platform/ZL.DB.Core`（原名 `ZL.DB.Acc`）及其全部引用方
性质：**纯命名对齐**（未更换 ORM 包、未改动代码逻辑）

## 1. 规则（一句话）

| 项目名 | 对应 ORM | 状态 |
| --- | --- | --- |
| **`ZL.DB.Core`** | **SqlSugarCore**（`Directory.Packages.props` 统一版本，当前 5.1.4.146） | ✅ 当前唯一实现 |
| `ZL.DB.Acc` | 旧 SqlSugar 线 | ❌ 已弃用的旧名，**不要再新建引用** |

**为什么叫 Core**：因 SqlSugar（旧线）的问题需要调整，项目更名为 `ZL.DB.Core`，与它实际使用的
**SqlSugarCore** 对应。

> ⚠️ 具体触发问题（现象 / issue / 影响版本）**尚未在本仓留档**，此处不臆造；
> 建议由提出人补一行到本节，便于后人判断「能否回退」。

## 2. 已核实的事实（2026-10-07）

- **改名前后 csproj 的包引用逐项一致**：`SqlSugarCore` / `MySql.Data` / `Oracle.ManagedDataAccess.Core` /
  `System.Data.SQLite.Core` / `System.Data.SqlClient` / `System.Data.OleDb` /
  `System.Configuration.ConfigurationManager` / `NLog` / `ZL.PFLite` —— 即本次是**命名对齐**，
  不是换 ORM 包。
- **项目内部是干净的纯改名**：22 个文件与旧项目 1:1 同相对路径；按正确编码（utf-8-sig）解码后
  **行级比对零差异**（仅名称 token 不同；其中 2 个文件另做了 CRLF 归一化，属格式层）；
  git 独立判定为 22 个 R088–R100 重命名；新 csproj 已声明 `AssemblyName`/`RootNamespace = ZL.DB.Core`；
  sln 条目改名且**保留原 GUID**。
- **无字符串级引用**：全仓不存在 `Assembly.Load("ZL.DB.Acc")` / `InternalsVisibleTo` 之类的
  程序集名字符串引用（已扫描 cs/csproj/props）。
- **跨仓无包消费者**：`tmom` 与 `UseThink.Iot/api` 各有一处提及 `ZL.DB.Acc.Repository`，
  但都在**代码注释**里（非 `PackageReference`、非 `using`）——改名不破坏其构建。
- **包名可用性**：`ZL.DB.Core` 在 nuget.org **未被占用**（可用）；旧名 `ZL.DB.Acc`
  现归属 `UseThink IoT Team`，最新 2.2.4（即本团队自己发布的最后一版）。

## 3. 改名必须同步的位置（本次实际处理清单，供下次改名复用）

| 位置 | 说明 |
| --- | --- |
| 项目目录 + csproj | `AssemblyName` / `RootNamespace` / `PackageId` |
| `IoT.Sdk.sln` | 项目条目（**保留原 GUID**，否则依赖关系断） |
| 消费方 csproj | 5 处 `ProjectReference` 路径（ZL.Iot.Plugin / ZL.EdgeService / ZL.Biz.Execute / ZL.Dao.Edge / ZL.Dao.IotDevice） |
| 消费方源码 | 41 处 `using ZL.DB.Acc;`（含限定引用） |
| **`obfuscar.xml`** | `<Module file="$(InPath)\…dll" />` —— **最易漏**，漏了混淆会找不到模块 |
| `pipeline.json` | 发布清单的 `name`（= 产出 nupkg 名）与 `csproj` 路径 |
| `Directory.Packages.props` | 残留的包版本条目 |
| 活文档 | `AGENTS.md`、`docs/15_项目对照表` |

**易漏点排序**（本次实测）：`obfuscar.xml`（清单外文件类型）> 消费方 `using`（数量多）> 发布清单。

## 4. 遗留与提醒

1. **包身份随之变化**：发布名 `ZL.DB.Acc` → `ZL.DB.Core`。旧名最后一版为 2.2.4（本团队所有），
   改名后不再更新；新名 nuget 可用。
2. **带日期的历史文档**：`docs/13/14/19/20/21/22` 是当时的架构分析/决策记录，保留旧名不改历史
   （如需全量统一由维护者决定）。
3. **跨仓注释**：`tmom`、`UseThink.Iot/api` 各一处注释提到 `ZL.DB.Acc.Repository`，可择机更新
   （纯注释，不影响构建）。
